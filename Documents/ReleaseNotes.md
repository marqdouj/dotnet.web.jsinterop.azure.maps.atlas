## Release Notes
- ### `11.1.0`. 
  - Internal updates.
  - `Global Script`.
	- The scripts generated by this library now include two scripts; one as a module (the default) and a global (browser level) script that you can use with your own custom JS Interop, if desired.
	- If you don't need the global script then you can ignore it. Don't add the reference in App.razor if you are not going to use the script.
	- See the `Sandbox/Custom (JS Interop)/Controls (Global)` page for an example.
- ### `11.0.1`. 
  - Replace existing 'module task' extensions with new [Extensions Package](https://www.nuget.org/packages/Marqdouj.DotNet.Web.JsInterop.Extensions/).
- ### `11.0.0`. 
  - Initial Production release of the library.
